# AlphaPi 蓝牙翻页器 · 精简版

基于 [shj4588/AlphaPi_STEM-PageTurner](https://github.com/shj4588/AlphaPi_STEM-PageTurner) V1.0.5 开发，保留原作者的 Git 历史与 AlphaPi 点阵、按键驱动。当前编译版本 **0003**。

面向 AlphaPi Zero / STEM ESP32-C3（4 MB Flash）。日常通过三个实体按键切换用途和控制设备，支持记住三个蓝牙主机、每次连接其中一台。

## 日常操作

| 操作 | 功能 |
| --- | --- |
| A 短按 | 循环切换已启用的用途，停止正在执行的自动翻页 |
| A 长按约 0.8 秒 | 打开设备管理 |
| B 短按 | 下一页、右方向键或下一条视频 |
| C 短按 | 上一页、左方向键或上一条视频 |
| A+B 同时按住约 1.2 秒 | 打开或关闭 Web 配置热点 |

模式切换时点阵显示约 2 秒。

| 模式 | 点阵 | B / C 默认动作 |
| --- | --- | --- |
| Page | P | PageDown / PageUp |
| Arrow | 双向箭头 | → / ← |
| Music 视频 | 播放三角形 | 下一曲 / 上一曲媒体键 |
| Custom | C | Web 配置的键盘键或媒体键 |
| Auto | A | 启停自动重复目标模式的 B / C 动作 |

默认只启用 Page、Arrow、Music。Custom 和 Auto 在 Web 页面开启后加入 A 键切换列表。视频模式沿用 Music 的媒体键，已有用户反馈可控制抖音，具体设备和 App 的响应需要实测。

Auto 运行时 B/C 互斥，按当前正在执行的键会停止，按另一个键会立即换方向。切换模式、管理设备、打开设置或蓝牙断开时自动停止。重连后需手动重新启动。

## 三设备配对和切换

长按 A 进入管理后松开，点阵显示当前位置的 A/B/C 字母和底排编号点。

| 管理界面操作 | 功能 |
| --- | --- |
| A / B / C 短按 | 切换到位置 1 / 2 / 3 |
| A / B / C 长按约 0.8 秒 | 为位置 1 / 2 / 3 开启 60 秒配对窗口 |

进入配对窗口后，在目标设备蓝牙设置里选择 **AlphaPi Turner**。重新配对会替换该位置的旧配对记录。不同位置用于不同主机，配对身份及当前位置断电保存。若曾刷过原版固件且连接异常，先在主机上忽略旧设备，再重新配对。

管理界面无操作 6 秒退出。底排 1～3 个点表示设备编号，上方实心菱形常亮表示等待回连，配对时菱形每 200 毫秒亮灭一次，编号点保持常亮。连接成功显示小方框和编号点约 2 秒。

## Web 配置

1. 同时按住 A+B 约 1.2 秒，点阵显示 **W**。
2. 手机或电脑连接 **AlphaPi-Config**，密码 **alphapi123**。
3. 浏览器打开 **http://192.168.4.1/**。
4. 修改并保存设置，长按 A 退出设置，恢复蓝牙。

配置页面提供以下选项。

- 启用 Custom，分别设置 B/C 最多三个 HID 用法编号及键盘/媒体类型。0 表示留空，键盘修饰键可与普通键组合，媒体键逐个发送。
- 启用 Auto，选择 Page、Arrow、Music 或已启用的 Custom 作为目标，设置 500 毫秒至 60 分钟的执行间隔。
- 设置空闲休眠时间、蓝牙广播间隔和发射功率。

常用十进制键盘编号为 PageDown=78、PageUp=75、→=79、←=80、↓=81、↑=82、空格=44、回车=40。设置保存后退出热点即可使用。

默认闲置 120 秒进入轻睡，蓝牙断开。A/B/C 任意键唤醒，唤醒这一按会被消耗。超时设为 0 可关闭休眠。设置、配对和自动执行期间保持运行。

## 源码与构建

依赖 macOS 的 zsh、Python 3、Git 和 Arduino CLI。

```sh
./build.command
```

构建脚本固定使用 ESP32 Arduino core **2.0.14**、NimBLE-Arduino **2.3.7**（提交 `a17bec675cd421a5f83bb5fe266fd5b498990aa4`）。首次构建会准备依赖，工具链保存在 `toolchain/`。可用 `ALPHAPI_TOOLCHAIN_DIR` 指定已有工具链目录。

| 路径 | 内容 |
| --- | --- |
| `AlphaPi_PageTurner.ino` | 模式、按键、配对提示和休眠 |
| `BleHid.*` | BLE HID 及三设备身份管理 |
| `Buttons.*`、`MatrixDisplay.*` | 原作者按键与点阵驱动 |
| `WebConfig.*` | 可选模式和高级设置 |
| `ModePolicy.h` | 模式启用与切换规则 |
| `VERSION`、`BuildVersion.h` | 四位编译版本，构建时同步生成串口标记 |
| `build/<版本>/` | 编译中间文件 |
| `firmware/output/<版本>/` | 可刷主程序镜像 |
| `docs/upstream/` | 原作者图片、硬件参考手册 |

运行模式规则回归检查。

```sh
c++ tests/mode_policy_test.cpp -o /tmp/alphapi-mode-test
/tmp/alphapi-mode-test
```

## 刷机

生成的 `AlphaPi-PageTurner-0003-app.bin` 是 ESP32-C3 应用镜像，写入 **0x10000**。

从已经运行 AlphaPi Arduino 固件的设备升级时先备份，选择主程序模式并保留原有引导和分区。全新板需另行准备匹配的 bootloader 和分区表。刷机工具应检查设备芯片、当前应用分区容量与启动选择。

迁移时保留旧固件的自定义键值、无线参数、空闲超时和三设备配对身份。首次使用精简配置时 Custom/Auto 隐藏，被裁掉的当前模式回到 Page。

0003 已完成整机编译、模式切换规则测试和镜像离线检查。三主机切换、热点保存、连续使用及唤醒操作的实机验收待完成。

原项目中的摇晃、游戏、KOReader、音量及播放控制独立模式已从此版本移除。历史源码可从上游或 Git 历史查看。KOReader 的独立固件尚待另行开发。
